# TCPioneer Labs

TCPioneer Labs is the experimental and development area of The Cyber Pioneer, focused on building, testing, and presenting cybersecurity tools and experimental projects.

## Status

The site is currently under development. New tools and projects can be added as they reach a usable state.

## Website

https://lab.tcpioneer.org/

## Current Direction

The lab is intended for:

- Cybersecurity experiments
- Security tooling prototypes
- Practical development work
- Research-driven projects
- Testing ideas before production release

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anandksri/lab.tcpioneer.org.git
cd lab.tcpioneer.org
```

Serve the directory with any static HTTP server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Responsible Use

Any security tools or experiments published here should only be used on systems and environments where you have permission to test.
